## What

Draft files in `knowledge/draft/` may be written in any language — they are scratch notes.
Promoted knowledge files must be in English so the knowledge base remains consistently searchable.
This convention was surfaced when a draft entry was written entirely in Japanese; the librarian
translated it during promotion without any explicit instruction, so the rule is now explicit.

## Do

- Accept draft files written in any language.
- Translate the content to English during the promotion step.

## Don't

- Promote a knowledge file in a non-English language.
- Require draft authors to write in English.
